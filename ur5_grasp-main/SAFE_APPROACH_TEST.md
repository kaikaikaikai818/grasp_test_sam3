# 安全观察点测试

此模式用于在抓取前验证双相机目标坐标和机械臂的安全接近路径。它不是抓取模式。

## 开启方式

在 `grasp_tool.py` 顶部保持：

```python
ENABLE_ROBOT_GRASP = False
ENABLE_SAFE_APPROACH_TEST = True
```

运行 `grasp_tool.py`。开始前请在示教器确认活动 TCP 为 `TCP_clamp`，手动把夹爪张开，并清空机械臂从当前位置上方到工作台之间的路径。

## 执行条件

程序只在以下条件同时满足时显示 `APPROACH READY 3/3`：

- D455 与 D435i 都通过视觉质量门槛；
- 已加载 `camera_alignment.json`；
- 两相机连续 3 帧得到同一目标；
- 两个基座坐标的差值不超过 15 mm；
- 目标和观察点都处于 `WORKSPACE_LIMITS` 内。

仅在此时，按已获得焦点的相机窗口中的 `P` 键才会发送运动命令。

## 运动路径

`P` 键只执行以下三步，速度和加速度均为 0.03：

1. 在当前 XY 位置垂直抬升到至少 Z=0.25 m；
2. 在安全高度将末端摆正为朝下；
3. 在不低于 Z=0.25 m 的高度，水平移动到目标正上方（目标上方至少 150 mm）。

该模式不会初始化或控制 COM10 夹爪，不会下降，不会关闭夹爪，不会调用完整抓取流程。P 键成功后会暂停 D455 的文字检测，防止移动中的夹爪被误显示为工具；D435i 画面仍保持实时显示。按 `Q` 只退出程序；它也不会自动回原位。

完成测试后，请把 `ENABLE_SAFE_APPROACH_TEST` 改回 `False`。
